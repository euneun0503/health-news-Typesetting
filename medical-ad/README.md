# 의료광고 문구 검사기

맞춤법 검사기처럼 의료광고 문구를 검사해 의료법 위반 소지가 있는 표현에 형광펜을 칠하고, 대치어·근거 조항·관련 위반 사례를 보여주는 정적 웹사이트입니다. 서버 없이 GitHub Pages로 바로 배포할 수 있습니다.

## 탭 구성
| 탭 | 내용 |
|---|---|
| 문구 검사 | 원문·교정문 비교, 위반 문구가 나온 문장 위치, 대치어 선택, 관련 사례 연결, 맞춤법·외래어 1차 교정, 나라 맞춤법 검사기 연결 |
| 위반 사례집 | 기사 중심의 판례·단속·공정위 사례(원문 위반 문구 형광펜 표시, 출처·매체·진료과·유형 필터) + 자동 수집 뉴스 아카이브 |
| 관련 법령 | 의료법 제56·57·27·42조 등, 시행령 제23·24조, 시행규칙 제40~42조, 행정처분 기준, 표시광고법·약사법 — 조문 검색과 국가법령정보센터 원문 링크 |
| 매체·심의 | 매체별 사전심의 여부와 판례, 매체별 사례 바로가기 |
| 명칭 표기 | 의료기관 명칭 표시 규칙 참고표 (간판은 개설 신고 명칭 그대로 쓰므로 별도 점검 없음) |
| 전문병원 기준 | 보건복지부 지정 분야별 7개 기준(환자구성비율·진료량·필수과목·의료인력·병상·의료 질·인증) 자가 점검 |
| 자가 점검표 | 게시 전 16개 항목 |

## 문맥 판단
단어만 찾지 않고 앞뒤 문맥을 봅니다. 예를 들어 "반드시 내원해서 검사를 받아야 합니다", "100% 예약제", "최초 내원 시", "완치가 가능한 것은 아닙니다", "명의 변경", "체험단 대가로 받은 후기는 게시하지 않습니다"는 위반으로 표시하지 않습니다. "보건복지부 지정 유방 전문병원"은 지정 분야이므로 '확인 필요'로만 표시합니다.

### 문맥 판단 예시 (오탐 제외)
- 표현을 경계하는 문장: "치료 후기를 검증해볼 필요가 있다", "최저비용 검색에 의존하기 보다는", "가짜 후기에 속지 마세요"
- 치료 후 일상생활: "달라붙는 바지도 통증 없이 입을 수 있게"
- 진료와 무관한 일반 서술: "젊은 층의 최대 화두는", "직장인의 최대 고민은"
- 대치어도 문맥에 맞게: "데이터에 완벽하게 부합" → '세밀하게/정밀하게', "완벽한 시술" → '꼼꼼한'

## 파일 구조
```
index.html                 화면과 검사 엔진(RULES)
data/cases.js              직접 검증한 위반 사례 (CASES)
data/reference.js          법령·매체·전문병원 기준·맞춤법 사전·점검표
data/news_auto.js          자동 수집 뉴스 (collector가 생성)
data/cases_auto.js         자동 수집 판례 (선택, collector가 생성)
collector/collect_news.py  Google 뉴스 RSS(+네이버 API) 기사 수집
collector/collect_prec.py  국가법령정보 Open API 판례 수집(선택)
.github/workflows/collect.yml  매일 자동 수집·커밋
```

## 배포
1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 이 저장소에서는 https://euneun0503.github.io/health-news-typesetting/medical-ad/ 로 열립니다
3. Settings → Actions → General → Workflow permissions를 **Read and write**로 바꿉니다.
4. Actions 탭에서 "Collect medical-ad news"를 한 번 수동 실행하면 뉴스 아카이브가 채워지고, 이후 매일 오전 6시대(KST)에 자동으로 쌓입니다.

### 선택: 수집 범위 넓히기 (Settings → Secrets and variables → Actions)
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 네이버 개발자센터 검색 API 키 → 네이버 뉴스까지 수집
- `LAW_OC`: open.law.go.kr에서 발급한 OC → 의료법 관련 판례 자동 수집

## 사례 추가
`data/cases.js`의 배열에 항목을 추가합니다. `phrases`에는 기사·판결에 나온 위반 문구를 **그대로**, `ad`에는 그 문구가 들어 있던 원문 문장을 넣으면 사례집에서 형광펜으로 표시되고 "검사기 탐지 n/m"으로 검사 규칙이 잡아내는지 확인할 수 있습니다.

## 규칙 추가
`index.html`의 `RULES`에 항목을 추가합니다. `skipA`(뒤 문맥 예외), `skipB`(앞 문맥 예외), `need`(주변에 있어야 하는 말), `neg`(뒤에 부정이 오면 제외), `dyn`(직접 판단 함수)로 문맥을 조정할 수 있습니다.

## 주의
- 자주 지적되는 표현을 찾는 참고용 1차 점검 도구이며 법률 자문을 대신하지 않습니다. 사전심의 대상 매체의 광고는 자율심의기구 심의를 받아야 합니다.
- 법령 탭은 조문 요지입니다. 따옴표 안만 원문이며, 정확한 현행 조문은 링크된 국가법령정보센터에서 확인하세요.
- 사례의 의료기관·의료인 이름은 익명 처리했습니다. 뉴스 수집기는 제목·언론사·날짜·링크만 저장합니다.
- 맞춤법은 자주 틀리는 표현 위주의 1차 교정입니다. 정밀 검사는 나라 맞춤법 검사기를 이용하세요.
